# מדוקס — התיקים של אינה (Inna Gat)

עותק עצמאי של מערכת מדוקס, מותאם לניהול תיקים רפואיים של **משפחה שלמה**.
המערכת המקורית (של קרן) נמצאת בשורש המאגר ולא שונתה — זהו שכפול נפרד.

## מה נוסף כאן: ניהול בני משפחה

בניגוד למערכת המקורית שמנהלת תיק של אדם אחד, כאן המסך הראשי מציג **בני משפחה**,
וכל בן משפחה הוא **תיק אישי נפרד** עם התיקיות לפי תחום רפואי שלו.

- **דינמי ובלי הגבלה** — אינה נכנסת ומקימה בעצמה כל תיק שתרצה (`+ בן משפחה`).
- לכל בן משפחה: שם, קרבה משפחתית, תאריך לידה וצבע לזיהוי.
- העלאת מסמך משייכת אותו אוטומטית לתיק שממנו נכנסו; חיפוש, תיקיות ושליחת מייל מסוננים לפי בן המשפחה.
- מחיקת בן משפחה מוחקת גם את כל המסמכים שבתיקו.

### מבנה
```
בני המשפחה (/)  →  תיק אישי (/member/[id])  →  תיקייה לפי תחום  →  מסמך
```

### קבצים עיקריים שנוספו
- `supabase/schema.sql` — טבלת `family_members` + עמודת `member_id` במסמכים
- `lib/schema.ts` — אתחול אוטומטי של הסכמה בזמן ריצה (`IF NOT EXISTS`)
- `app/api/members/**` — API ליצירה/עריכה/מחיקה של בני משפחה
- `app/member/[id]/**` — התיק האישי והתיקיות שבתוכו
- `components/MemberCard.tsx`, `components/AddMemberModal.tsx`, `lib/memberColors.ts`

## הרצה

```bash
npm install
npm run dev
```

משתני סביבה נדרשים (כמו במערכת המקורית): `DATABASE_URL`, `BLOB_READ_WRITE_TOKEN`,
`OPENAI_API_KEY`, `RESEND_API_KEY`, `PASSCODE`.

**בסיס נתונים:** יש להשתמש ב-DB נפרד משל קרן. הטבלאות נוצרות אוטומטית בפנייה הראשונה
ל-API, או ניתן להריץ ידנית את `supabase/schema.sql`.
